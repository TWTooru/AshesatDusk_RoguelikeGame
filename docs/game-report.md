## 1. 遊戲介紹與核心遊戲循環

《暮墓餘燼 Ashes at Dusk》是一款基於 2D 房間式 Roguelike 結構的黑暗奇幻生存動作遊戲。玩家扮演一名受到詛咒的獵魔人，在封閉的墓園房間中對抗湧入的黑暗生物。

### 核心玩法
- **極簡操作**：僅需使用 WASD 或方向鍵進行八方向移動。
- **全自動戰鬥**：武器（幽魂彈、骨刃環、冥火法陣）自動對最近目標攻擊。
- **七分鐘極限**：單局時間上限 420 秒，經歷 6 個戰鬥房間後，於第 7 房決戰 Boss「無首守墓人」。
- **路線決策**：每房清除後提供「武器祭壇」、「禁忌能力」、「療癒聖泉」、「詛咒寶箱」兩扇具危險度標示的門。

```
[標題畫面] ➔ [戰鬥房間 1~6] ➔ [清房擇門 (路線決策)] ➔ [三選一升級 / 詛咒] ➔ [第 7 房 Boss 戰] ➔ [結算畫面]
```

## 2. 市場需求與產品定位

本作品鎖定喜愛短時間遊玩、快速獲得強烈成長感與隨機構築樂趣的玩家群：

- **低門檻上手**：汲取《Vampire Survivors》類型的無目標瞄準與全自動攻擊，大幅降低操作壓力。
- **短局高密度**：適應現代零碎時間，7 分鐘內必定完成一局（包含開場、成長、路線決策與 Boss 高潮）。
- **熟悉帶有差異**：在倖存者類型的爽快清怪基礎上，導入《Hades》式的「雙門路線與風險報酬取捨」，創造豐富重玩價值。

## 3. 開發工具與技術棧

- **遊戲引擎**：Godot 4.7.1 (`GDScript 2.0`)

- **測試框架**：Godot Headless 原生測試腳本 (`tests/support/test_case.gd`, `tests/run_all.ps1`)
- **AI 輔助工具**：Gemini / Codex (規格整理、TDD 腳本撰寫、圖像產生)

---

## 4. 開發過程 (Development Process)

1. **前期規劃與規格定案**：確定 7 分鐘 7 房間結構、確定武器（幽魂彈/骨刃環/冥火法陣）與 4 種敵人 + Boss 招式。
2. **測試驅動開發 (TDD)**：先撰寫 Headless 測試（如 `test_run_domain`, `test_upgrade_catalog`, `test_boss`），確保邏輯無誤後再實作組件。
3. **組件與 UI 構建**：建立 code-drawn 像素風格圖形，確保碰撞輪廓 100% 精確；建構響應式 HUD 與升級卡片介面。
4. **展示模式與重現性**：實作 Demo Mode (75 秒快節奏，固定種子 4701)，支援一分鐘示範影片錄製。
5. **全自動驗收**：撰寫 `run_all.ps1` 進行全套Headless 測試與編輯器解析檢查。

## 5. AI 使用揭露 (AI Usage Disclosure)

在專案開發過程中，AI 工具運用於以下範圍：
- **規格與計畫編寫**：整理設計規格與步驟分明之實作計畫。
- **程式碼協作與測試生成**：協助建構 GDScript 邏輯與 Headless 測試斷言。
- **視覺素材輔助**：生成墓園背景 (`assets/generated/graveyard_background.png`) 與標題圖騰 (`assets/generated/title_art.png`)。

**聲明**：所有碰撞箱、傷害計算、Boss 招式狀態機、房門抽選與遊戲控制邏輯，均由 Godot 原生 GDScript 代碼與自動化測試嚴格規範，不依賴 AI 即時運作。
