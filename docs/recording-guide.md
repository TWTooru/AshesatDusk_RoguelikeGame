# 《暮墓餘燼 Ashes at Dusk》一分鐘展示影片錄製指南

本指南提供使用者自行錄製並剪輯 60 秒 MP4 展示影片的標準腳本、分鏡表、建議側錄設定與繁體字字幕文案。

---

## 1. 建議錄製與側錄設定

- **錄製軟體**：OBS Studio / NVIDIA ShadowPlay / Windows Xbox Game Bar
- **解析度**：1920 × 1080 (1080p, 16:9)
- **影格率**：60 FPS
- **音訊設定**：48 kHz / 立體聲
- **建議模式**：建議在標題畫面選擇「**快速展示模式**」，該模式採用固定種子 (`4701`) 且波次快速流暢，能在 60 秒內錄製完畢所有關鍵畫面。

## 3. 剪輯與輸出建議

1. **背景音樂**：可直接使用遊戲內建音效與背景音，或搭配 120-130 BPM 輕快黑暗奇幻風格無版權 BGM。
2. **影片格式**：MP4 (H.264 / AAC).
3. **字體建議**：字幕建議使用思源黑體或微軟正黑體粗體，文字加黑色邊框以提升可讀性。
