# 暮墓餘燼 (Ashes at Dusk) - EMBERS Roguelike Game

《暮墓餘燼 Ashes at Dusk》是一款基於 **Godot 4.7.1** 開發的 2D 房間式 Roguelike 自動攻擊生存動作遊戲。遊戲採用獨特的**文字符號視覺風格**，將玩家、怪物、Boss 與彈幕以高對比中文書法文字直接繪製於遊戲世界中。

---

## 🎮 玩家新手遊戲指南 (How to Play)

如果你是一位第一次進入《暮墓餘燼》的玩家，請按照以下步驟開啟你的獵殺之旅：

### 1. 遊戲目標 (Objective)
你扮演一位受詛咒的獵魔人「**玩家**」。
你的目標是在充滿怪物的大陸上存活，通過 **4 個房間（展示模式）** 或 **7 個房間（正式模式）** 的考驗，並擊敗第 7 關的最終 Boss「**無首守墓人**」！

### 2. 基本操作與戰鬥 (Controls & Combat)
- **移動 (Move)**：按下鍵盤 `W` / `A` / `S` / `D` 或 `方向鍵`，自由控制「玩家」在場地內八方向移動。
- **自動攻擊 (Auto Attack)**：你**不需要點擊滑鼠或手動瞄準**！主角身上的武器（如預設的 `幽魂彈`）會自動追蹤並打擊周圍最近的敵人。
- **躲避與生命值 (Dodge & HP)**：拉開與敵人（`腐屍`、`骸骨弓手`、`暗影蝙蝠`、`墓園騎士`）的距離。受到傷害時主角會閃爍紅色，畫面左上方會即時更新剩餘生命（例如 `生命: 100 / 100`）。

### 3. 能力升級與吸血機制 (Upgrades & Lifesteal)
- 進入房間獎勵或升級時，畫面上會彈出 3 張升級卡牌。
- 可以使用**滑鼠點擊**或鍵盤數字鍵 **`1` / `2` / `3`** 快速選擇能力：
  - 攻擊型：解鎖 `骨刃環`（環繞護體刃）、`冥火法陣`（範圍持續灼燒）。
  - 強化型：提升移速、傷害倍率、減傷率，或是獲得 **`冥血渴望` (傷害吸血 Lifesteal)**。
  - **吸血效果**：獲得吸血後，你發射的所有 `幽魂彈`、`骨刃環` 每次造成傷害，都會依比例為你恢復生命（此時「玩家」文字會**閃爍亮綠光**！）。
- 選擇能力時**時間完全暫停**，可以安心思考。

### 4. 實體進門與路線決策 (Entering Rooms)
- 每當房間內波次敵人被清空，左右牆壁會出現亮綠色的門戶標示（例如 `【走進左門: 武器祭壇】` 與 `【走進右門: 詛咒寶箱】`）。
- **如何進入下一關**：操控「玩家」**直接走進左側或右側邊界牆壁**，即可自動傳送至下一關！
- **門戶類型**：
  - **武器祭壇**：獲得 1 次武器/能力升級
  - **禁忌能力**：獲得 1 次屬性強化
  - **療癒聖泉**：立即回復 35 HP 並提升 5 HP 上限
  - **詛咒寶箱**：敵人數量增加 35%，但可獲得 2 次雙重卡牌升級！

### 5. Boss 戰與通關 (Boss Battle)
- 抵達最後一關時，大 Boss「**無首守墓人**」登場！
- 觀察 Boss 的紅色招式預警（衝鋒預警線、召喚墓碑圈、冥界彈幕），利用移動閃避，配合你的武器與吸血能力將其消滅，即可贏得勝利！

## 📖 遊戲介紹 (Game Overview)

### 核心特點
- **文字符號視覺藝術 (Text-Based Visual Art)**：
  遊戲中無繁雜貼圖，角色與怪物皆為高對比中文字體（`玩家`、`腐屍`、`骸骨弓手`、`暗影蝙蝠`、`墓園騎士`、`無首守墓人`），搭配 4 方向深黑描邊與 HSL 亮彩，兼具視覺衝擊與極致流暢度。
- **自動瞄準與戰鬥 (Auto-Attacking Combat)**：
  玩家專注於 WASD 走位與拉扯，3 種特色自動武器（`幽魂彈`、`骨刃環`、`冥火法陣`）會自動追蹤或繞行打擊敵人。
- **實體走門房間系統 (Physical Door Transition)**：
  每當房間敵人清空，左右兩側牆壁會開啟亮綠色實體門戶。玩家只需控制角色直接走進左門或右門即可進入下一關。
- **選單與能力暫停 (Pause During Upgrade)**：
  當進入能力選擇卡牌或房間門戶選擇時，遊戲倒數計時器會完全暫停。
- **磨砂玻璃 UI 著色器 (80% Blur Shader)**：
  標題畫面、能力選擇卡牌與戰報頁面均配備 80% 畫面的 Screen Blur Shader。

## 🛠️ 開發工具 (Development Tools)

- **遊戲引擎 (Engine)**：Godot Engine `v4.7.1.stable` (GDScript 2.0)
- **開發與調試環境**：Windows 11 PowerShell, Godot Headless CLI execution
- **測試框架 (Test Framework)**：自研輕量化自動測試套件（11 項單元與整合測試，支援 Headless 執行）
- **著色器與視覺 (Shaders & Rendering)**：
  - Godot 2D Canvas Shader (`hint_screen_texture` 80% Mipmap Blur)
  - GDScript `draw_string` 幾何與字型基線（Ascent/Descent）精確對齊
  - 4-Directional Outline 筆刷演算法
- **圖像處理工具**：Python Pillow (PIL)
- **版本控制 (VCS)**：Git & GitHub (`TWTooru/EMBERS_RoguelikeGame`)

## 📜 開發過程說明 (Development Process)

### 階段一：核心框架與遊戲機制建立
1. **架構設計**：確立專案架構（`src/core` 狀態機與領域邏輯、`src/player` 玩家運動學、`src/enemies` 敵人 AI、`src/combat` 武器控制器、`src/rooms` 房間生成器）。
2. **自動測試優先**：編寫 `tests/run_all.ps1` 與 11 個測試腳本，確保所有領域邏輯皆可自動驗證。

### 階段二：文字符號視覺革新 (Text-Based Transformation)
1. **視覺風格轉變**：將幾何圖形實體全面替換為中文文字繪製。
2. **精確字型基線對齊**：解決中文字體偏下問題，採用 `(font.get_ascent() - font.get_descent()) / 2.0` 公式將文字幾何中心完美鎖定於實體 `(0, 0)` 物理碰撞中心。

### 階段三：高對比視覺與磨砂玻璃 UI 強化
1. **圖層與高對比修正**：將怪物與彈幕文字提升至 `z_index = 10+`，並加入 4 向深黑描邊與放大字體。
2. **80% 螢幕模糊背景**：編寫 `blur.gdshader`，為主畫面、升級選單與結算面板加入高級磨砂玻璃模糊背景。

### 階段四：玩家體驗（UX）與操作優化
1. **實體走門進關**：玩家清空房間後直接操控角色「走進左門/右門」即可進入下一關。
2. **獨立彈幕座標系與吸血修復**：修正 `Soul Bolt` 彈幕巨量打擊時的傷害記錄與吸血觸發，並新增玩家受傷（紅閃）與吸血（亮綠閃）之即時視覺回饋。
3. **能力選擇時間暫停**：暫停計時器於升級階段，保障玩家思考時間。
4. **展示模式調校**：將展示模式設定為 1 分鐘 / 4 關，便於快速驗收。

### 階段五：匯出與穩定性修正
1. **匯出警示與讀取修復**：修正 `Image.load_from_file` 的相對路徑警告。
2. **空值腳本防護**：修正 `RoomManager._spawn_boss` 中 CharacterBody2D 實例化與腳本掛載順序。

## 🚀 快速啟動與測試 (Quick Start)

### 執行遊戲
```powershell
& 'C:\Users\user\Desktop\Godot_v4.7.1.exe' --path .
```

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run_all.ps1
```
